# Changelog

All notable changes to KapdaKhata are documented in this file.

## [1.0.0] - 2026-09-16

### First public release

- Home dashboard with monthly profit, sales, and expense summaries
- Product catalog with categories, stock, photos, and detail views
- Sell flow with multi-item sales, custom name suggestions, and profit calculation
- Expense tracking with categories and date filters
- Reports with monthly trends and breakdowns
- Settings for shop profile, categories, sale suggestions, theme, and notifications
- More menu with backup/restore, CSV exports, and sample data
- Local SQLite storage with daily automatic backups
- Low-stock notification screen
- Purple brand theme across the app
